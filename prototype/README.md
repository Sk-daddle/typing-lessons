# TypeQuest

A complete touch-typing course for homeschool kids, packed into a single HTML file. No install, no build, no internet required (fonts degrade gracefully offline) — open `index.html` in any browser on a computer with a keyboard.

## What's inside

**41 lessons across 7 units**, from first keystrokes to full paragraphs:

1. **Home Row Harbor** — F/J through the full home row, first real words
2. **Top Row Trail** — E/I, R/U, T/Y, W/O, Q/P and two-row words
3. **Bottom Row Bay** — the rest of the alphabet, pangrams
4. **Capital City** — shift keys, capitals, `. , ? ! ' "`
5. **Number Mountain** — the number row with correct fingering
6. **Word Wizard Woods** — common words, digraphs, double letters, silly sentences
7. **Story Summit** — paragraphs, timed tests, accuracy challenge, graduation run

**3 arcade games** unlock as units are completed, and only use keys the student has learned:

- 🌧️ **Letter Rain** — zap falling letters before they splash
- 🎈 **Balloon Pop** — type words to pop balloons before they float away
- 🚀 **Rocket Race** — a 45-second typing race against Robo-Rocket

**Also:**

- Multiple student profiles (one computer, many kids)
- On-screen keyboard with color-coded fingers and next-key highlighting
- Live WPM + accuracy, 1–3 stars per lesson, star-gated progression
- A "for grown-ups" progress report with per-lesson stats, a speed chart, and coaching tips
- A printable graduation certificate
- Progress saved locally in the browser (`localStorage`) — no accounts, no server

## Running it

Open the file directly, or serve the folder:

```bash
open index.html
```

## Notes for parents

- Accuracy before speed: stars reward accuracy first; speed targets rise gently by unit (8 → 20 WPM for the third star).
- Ten minutes a day beats an hour a week.
- Progress is per browser per computer. Clearing browser data erases it; the progress screen also has an explicit reset.
